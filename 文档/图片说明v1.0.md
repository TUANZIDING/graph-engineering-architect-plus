# 图片说明

仓库里的每一张图都由仓库内的示例 JSON、真实命令输出或网页本身生成，不使用 AI 绘图，可一键重建。

| 图片 | 生成方式 |
| --- | --- |
| `主图/封面v1.0.jpg` | `工具/制作配图v1.0.py`：两张真实拓扑图（正例、反例）+ 标题排版，无头 Chromium 渲染 1600×900 @2x |
| `../图片/拓扑图/*-v1.0.svg / .webp / -sm.webp` | `工具/绘制拓扑图v1.0.py` 读取 `示例/*.json`，分层布局；红框节点为 `diagnose` 指出的问题节点 |
| `../图片/示意图/十一类病灶v1.0.webp` | `工具/制作配图v1.0.py`：11 类病灶与英文代码 |
| `../图片/示意图/修复顺序v1.0.webp` | 同上：repair_layer 1 → 6 |
| `../图片/示意图/快慢分层v1.0.webp` | 同上：执行 / 验证 / 审计 / 治理 / 人 |
| `截图/终端诊断截图v1.0.png` | 同上：实际运行 `geaplus-v1.1.py validate` 与 `diagnose` 的输出 |
| `截图/桌面截图v1.0.png`、`截图/示例对照截图v1.0.png` | `工具/渲染图片v1.0.py` 截取 `index.html`（1440 px） |
| `截图/手机截图v1.0.png`、`截图/手机示例截图v1.0.png` | 同上（390 px @2x） |

## 重建全部图片

```bash
pip install playwright pillow && python3 -m playwright install chromium
python3 工具/制作配图v1.0.py
python3 工具/构建网页数据v1.0.py
python3 工具/渲染图片v1.0.py index.html 文档/截图/桌面截图v1.0.png --width 1440 --height 900 --scale 1
python3 工具/渲染图片v1.0.py index.html 文档/截图/示例对照截图v1.0.png --width 1440 --height 1000 --scale 1 --anchor "#lab"
python3 工具/渲染图片v1.0.py index.html 文档/截图/手机截图v1.0.png --width 390 --height 844 --scale 2
python3 工具/渲染图片v1.0.py index.html 文档/截图/手机示例截图v1.0.png --width 390 --height 844 --scale 2 --anchor "#tabs"
```
