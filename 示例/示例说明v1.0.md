# 示例说明

四张图覆盖一个正例、一个反例和一组“修复前 / 修复后”。拓扑图见 [`../图片/拓扑图/`](../图片/拓扑图/)，真实命令输出见 [`../验证/运行记录v1.1.md`](../验证/运行记录v1.1.md)。

| 文件 | 场景 | 格式 | diagnose | 要点 |
| --- | --- | --- | --- | --- |
| [`faers-manuscript-graph-v1.1.json`](faers-manuscript-graph-v1.1.json) | FAERS/JADER 药物警戒论文 | v1.1 | healthy | 复算者不看主代码，只拿冻结的数据快照；阴性对照药物盯住假阳性；仲裁优先级“复算一致性 > 假阳性控制 > 信号数量” |
| [`broken-circular-graph-v1.0.json`](broken-circular-graph-v1.0.json) | 同一篇论文的“自我确认”写法 | v1.0 | blocked | 删掉反指标、复算者读主分析代码、复算与分析同一 owner、锚点 106 天未复核 |
| [`legacy-trauma-audit-graph-v1.1.json`](legacy-trauma-audit-graph-v1.1.json) | 急诊创伤病历质控（修复前） | version: 1 旧格式 | blocked | 字段齐全，但锚点只连书写医生、质控员拿不到原始记录（看守剧场）、补写 ↔ 核对没有轮数上限 |
| [`legacy-trauma-audit-graph-repaired-v1.1.json`](legacy-trauma-audit-graph-repaired-v1.1.json) | 同上（修复后） | version: 1 旧格式 | healthy | 加锚点 → 质控员、病历与核对报告 → 反指标三条边，加轮数上限与锚点有效期 |
| [`faers-manuscript-graph-v1.0.json`](faers-manuscript-graph-v1.0.json) | 正例的 v1.0 版本 | v1.0 | healthy | 供 v1.0 回归测试使用 |

每个 `.json` 旁的 `.mmd` 是 `geaplus mermaid` 导出的 Mermaid 拓扑，可直接贴进 GitHub Markdown 或 Obsidian。

## 自己跑一遍

```bash
T=工具/graph-engineering-architect-plus/scripts/geaplus-v1.1.py
python3 $T validate 示例/legacy-trauma-audit-graph-v1.1.json
python3 $T diagnose 示例/legacy-trauma-audit-graph-v1.1.json --today 2026-11-15
python3 $T validate 示例/legacy-trauma-audit-graph-repaired-v1.1.json
python3 工具/绘制拓扑图v1.0.py 示例/broken-circular-graph-v1.0.json /tmp/broken.svg --title 反例
```

示例中的药物、病历与人员均为示意，不含真实患者数据。
