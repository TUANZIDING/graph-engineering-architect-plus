# geaplus 评测报告 v0.3（留出任务 t14–t18，2026-11-15）

## 结论
1. 语义断言再次饱和：44/45 份全过，三组 99% / 100% / 100%，**不能区分有无 skill**。唯一失分：unguided-t17-r1「调整者不能改裁判」。
2. 结构缺陷差异巨大且稳定：图任务（t14–t17，每组 12 份）里，unguided 12/12 有真实 validate 错误（E-STATE 12/12、E-GOODHART 10/12、E-FAIL 10/12、E-VNOTEETH 8/12、E-CIRCULAR 5/12 等）；g11 与 g12 用各自版本校验 **0/12 有 validate 错误**。注意这是 geaplus 自己定义的指标，有自指偏差。
3. g11 vs g12：在 validate 错误这一项上打平（都是 0）。g12 12/12 声明了 domain（v1.2 新字段），g11 0/12。没有证据显示 v1.2 在设计质量上胜过 v1.1。
4. **发现的真缺陷（v1.1 与 v1.2 共有）**：设计阶段尚未有人确认的锚点，Agent 诚实地把 last_confirmed 留空，diagnose 却报 decayed_measurement → at_risk。g11 3/12、g12 8/12 因此被判结构不过；剔除这一项后 g11 12/12、g12 12/12 全部通过。v1.2 的 E-STALE 引导让更多 Agent 选择留空，所以受罚更多。合理语义应是「未确认/待复核」(pending_revalidation)，不是「过期」。仅 2/12 份 g12 主动用了 revalidation_gate 拿到 pending_revalidation。
5. t18（简单排班导入）：9/9 正确判为 direct/linear_workflow，没有过度建图。
